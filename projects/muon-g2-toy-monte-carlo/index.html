Muon g-2 & PSXM modelling

Research · April and July–September 2026 · Scientific Python

A toy Monte Carlo study of the muon g-2 measurement: generating synthetic decay-positron time spectra with the characteristic exponential decay modulated by the anomalous precession ("wiggle plot"), then fitting the precession frequency back out and examining residual structure. A related summer study investigated a six-coil PSXM magnet model for spiral injection.

Python Simulation Data analysis

Overview

The muon's anomalous magnetic moment is one of the most precisely measured quantities in physics, and the experimental method — extracting the anomalous precession frequency ωa from the time distribution of decay positrons — is a beautiful exercise in statistics. This project rebuilds that pipeline at toy scale: generate pseudo-data, fit the time spectrum and compare the estimated frequency with the known input. One saved fit differs from that input by 0.64 reported standard errors; this is a single-fit comparison.

Analysis and implementation

The toy pipeline uses N(t) = N₀ e−t/τ[1 + A cos(ωat + φ)] for the five-parameter time-spectrum fit. I worked on its Python generation and analysis code, debugging, fitting and visualisation, with AI-assisted implementation in the first version. Saved outputs contain 10.99 million selected positron counts. I compared toy and ROOT-data residuals using FFT analysis and documented assumptions and mismatches in a 12-page technical report.

PSXM Magnet Design

Shanghai Jiao Tong University · Summer research, July–September 2026

I formulated a six-coil magnet model in Python/NumPy and used least-squares current solves to investigate dipole and quadrupole field patterns. I compared numerical results with an analytic ideal-shell reference and examined the trade-off between shielding radius and field capability within the 2D approximation.

I co-authored a 19-page design report with Zejia Lu under Professor Liang Li and presented the study to SJTU–KEK collaborators. The results describe a numerical magnetostatic model, not measured hardware performance.

Tech stack

Python · NumPy for event generation · SciPy / least-squares fitting · Matplotlib for the wiggle plots and residuals.
